# playwright-dotnet-mstest-reqnroll
Demo repository to show Playwright .NET test framework capabilities

The WebApp provides a product table and CRUD screens backed by ProductAPI. Run ProductAPI (`http://localhost:5044`) and then WebApp (`http://localhost:5168`) using their `http` launch profiles. To use another API address, set the `ProductApi:BaseUrl` configuration value (for example, the `ProductApi__BaseUrl` environment variable).
